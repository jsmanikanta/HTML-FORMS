# HTML Forms

A simple beginner-friendly project that demonstrates how to create basic forms using HTML. This repository contains a single HTML file with multiple common input fields that help in understanding form structure and user input collection. :contentReference[oaicite:1]{index=1}

## Features

This project includes examples of:

- Full name input
- Age input
- Password field
- Email field
- URL field
- Mobile number input
- Rating input
- Date input
- Time input
- Week input
- Color picker
- Checkboxes
- File upload
- Description textarea
- Option selection
- Register button

These are all visible from the `forms.html` file in the repository. :contentReference[oaicite:2]{index=2}
